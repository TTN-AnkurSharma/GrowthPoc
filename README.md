# Low-Level Design Learning POC

This repo has two folders. Read them in order.

## Folders

### `lld`

Checkout example that shows SOLID in one flow.

### `url-shortener`

Simple Spring Boot URL shortener using one domain entity and an H2 database.

## How to run

JDK 17 or newer.

```bash
./gradlew :lld:run
./gradlew :url-shortener:bootRun
```
